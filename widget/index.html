Model: mixed‑precision training memory per the ZeRO paper (Rajbhandari et al., 2020). Per parameter each GPU stores weights (P_b), gradients (P_b), and optimizer state (K fp32 bytes: for Adam, a 4‑byte master copy + 4‑byte momentum + 4‑byte variance = 12). ZeRO‑1 shards the optimizer (K/N), ZeRO‑2 also shards gradients, ZeRO‑3 shards everything ((2P_b+K)/N). Communication is the ring‑algorithm volume: 2Ψ for ZeRO‑0/1/2 and 3Ψ for ZeRO‑3. This models model‑state memory only — activations, temporary buffers, and CPU/NVMe offload (ZeRO‑Infinity) are out of scope. Built to accompany the from‑scratch simulation notebook.
